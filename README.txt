IBM Semeru Runtime Certified Edition, Version 17
================================================

This README file applies to version 17, release 0, modification 3, fix pack 0 (VRMF 17.0.3.0), and to all subsequent releases, modifications, and fix packs, until otherwise indicated in a new README file.

This release is compatible with the Oracle Platform Java(TM) Standard Edition (Java SE) 17 application programming interfaces (APIs). The SDK is built from the following components:

- OpenJDK 17 class libraries
- Eclipse OpenJ9 Java virtual machine
